Plot layout: stacked vs grid

3 variables selected (CNDC, SSPS, T2). Which arrangement in the main window?

A

Stacked, full width

One plot per row, shared x-axis (time) below the bottom plot only. Zoom/pan on any plot syncs all of them since they share the same time axis. Best for comparing timing of events across variables.

B

2-column grid

Plots wrap into a 2-column grid once more than 2 variables are selected. Each plot keeps its own x-axis labels. More compact vertically, but harder to visually line up a spike in one variable with the same moment in another.
